# PRCOMM

Site web du projet PRCOMM.

## Structure du projet

```
PRCOMM/
├── index.html       ← Page d'accueil
├── css/             ← Styles
├── js/              ← Scripts
└── pages/           ← Pages supplémentaires
```

## Comment contribuer

1. Avant de commencer à travailler :
   ```bash
   git pull
   ```

2. Après avoir fait des modifications :
   ```bash
   git add .
   git commit -m "Description de tes modifications"
   git push
   ```
